Important: This calculator reproduces the supplied workbook's formulas; it is not a current Nepal tax-law calculator. Basic is still derived from Gross using the incentive-tier assumption (as in the Check sheet), and Allowances stay at 40/60 of that Basic. SSF — both the monthly SSF line and the annual 31% SSF contribution used for the retirement-fund deduction — is calculated on the static "SSF Applicable Basic Salary Component" for the employee's salary range, not on the actual Basic. Incentive is then the residual needed to make Basic + Allowances + SSF + Incentive equal Gross, so it can differ slightly from the flat incentive-tier percentage shown above once the SSF cap is applied.
