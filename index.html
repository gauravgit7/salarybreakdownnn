How this works: The range's Applicable Basic Component is treated as if it were the Gross salary and run through the standard split: Basic = Component ÷ (166.67% + Monthly SSF%), Allowances = Basic ÷ 60% × 40%, SSF = Basic × Monthly SSF%. Because that divisor reserves exactly the right slice for SSF, Basic + Allowances + SSF always add back up to the Component exactly. Incentive is simply Gross − Component, so the four figures together always reconcile to the actual Gross. Separately, the annual SSF Contribution (used for the retirement-fund deduction) is Basic × 12 × Annual SSF Contribution %. If Gross doesn't fall inside any configured range, the Component defaults to the actual Gross (so Incentive = 0).
